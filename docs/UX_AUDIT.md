# UX 审计 — 用户工作流与按钮可见性规则

## 用户角色与核心场景

| 角色 | 场景 | 频率 | 核心动作 |
|---|---|---|---|
| 学习者 | 从 PDF/聊天生成脑图 | 高 | 新建 → 等待 → 查看/编辑 |
| 知识工作者 | 手动微调已有脑图 | 高 | 编辑节点 → 自动保存 |
| 复习者 | 重新生成（换角度） | 中 | 补充要求 → 确认 → 等待 |
| 导出者 | 打印/分享 | 低 | ··· → 选格式 |

## 可见性规则（三档）

### Tier 1 — 常驻工具栏（始终可见，不藏菜单）

| 按钮 | 图标 | 位置 | 禁用条件 |
|---|---|---|---|
| ☰ 侧栏切换 | ‹/☰ | 最左 | 无 |
| 本会话 | 文字 | 工具栏 | 无（aria-pressed 高亮） |
| 全部 | 文字 | 工具栏 | 无（aria-pressed 高亮） |
| 撤销 ↶ | ↶ | 工具栏 | !mapActions |
| 重做 ↷ | ↷ | 工具栏 | !mapActions |
| **重新生成** | ✦ | 工具栏（primary 色底） | panelRun running 或无 record |
| ⛶ 全屏 | ⛶ | 工具栏最右 | !mapActions |

### Tier 2 — ··· 溢出菜单（一次点击可达）

全部展开、全部折叠、折叠至第2层、预览SVG、导出JSON、导出Markdown、导出XMind、导出PNG、恢复上一版本(条件)、归档、删除。

### Tier 3 — Modal / Settings

Regenerate Modal（补充要求+来源提示+确认）、节点属性面板、新建脑图表单。
